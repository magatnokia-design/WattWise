Before you start

What you need

  • The WattWise Hub
  • The 5 V 3 A USB-C power supply supplied with the Hub
  • Your 2.4 GHz Wi-Fi name and password
  • A phone with the WattWise app installed
Use the supplied adapter, and keep the unit closed

Power the Hub from the supplied 5 V 3 A USB-C adapter only. It needs the full 3 A while both relays are switching, and a weaker charger can brown it out mid-command — which looks like a dropped connection rather than a power fault.

Do not open the enclosure. It carries mains voltage for the two switched outlets. Nothing inside is meant to be adjusted. If the housing or a lead is damaged, or either has been wet, leave it unplugged and have it checked before use.

How it works

A Hub with no Wi-Fi saved creates its own temporary network. Join it with your phone, tell the Hub which router to use, and it restarts onto your network. Then pair it to your account in the app.

Nothing is pre-programmed

Your Wi-Fi password is never compiled into the firmware. It is entered here, on the day, and stored on the unit.

1

Power on the Hub

Plug in the supplied USB-C adapter and wait about ten seconds. The setup network appears on its own — no button to press.

2

Join the setup network

In your phone's Wi-Fi settings pick the network above and enter its password. A “Sign in to network” notice appears within seconds — tap it. If nothing appears, browse to http://192.168.4.1

3

Choose your network

Pick your router from the list and type your Wi-Fi password. Nothing listed? Tap Rescan networks. The Hub sees 2.4 GHz only. Hidden router? Type its name into the hidden network box.

4

Save and connect

Tap Save and connect. The Hub restarts and joins your network; the setup network closes. If the password was wrong, it reopens so you can try again.

Scan the code on page 5

7

Check that it reports

The Hub card shows a status chip. Within a minute it should read Online, and live readings appear on the Dashboard.

Keep the token private

It lets a caller submit readings as this Hub. Do not post or screenshot it. If it gets out, issue a new one in the app — the old one keeps working briefly so the Hub does not drop out mid-change.

If something goes wrong

Troubleshooting

What you seeWhat to do
Setup network not listed Unplug, wait five seconds, plug back in. A Hub that already holds working Wi-Fi will not open one — reset it first (below).
Setup page never loads Browse to http://192.168.4.1. Turn mobile data off — some phones route around a network with no internet.
No networks in the list Tap Rescan networks. A 5 GHz-only network never appears.
Wrong Wi-Fi password Nothing to undo. The setup network reopens — rejoin and re-enter.
Setup network vanished It closes after 10 minutes and the Hub restarts. Power-cycle and start from step 1.
Moving to a new router Hold BOOT for 5 seconds. Wi-Fi is cleared; pairing is not affected.
App shows the Hub offline Check the Reason line on the Hub card, then confirm the token matches page 4 exactly.
Relays click but readings stay 0 Use the supplied 3 A adapter — a weak supply browns the Hub out while switching. If the adapter is correct, a very small load can also read zero, because the meter has a minimum it can see.
