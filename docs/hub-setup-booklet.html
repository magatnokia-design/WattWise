Before you start

What you need

  • The WattWise Hub
  • A USB-C power supply — provided by WattWise
  • Your 2.4 GHz Wi-Fi name and password
  • A phone with the WattWise app installed
Power over USB-C only

Never wire this unit into a mains socket. The PZEM meter terminals on this build are exposed, so mains wiring would put a live conductor within reach. USB-C supplies everything the Hub needs.

WattWise is for low-voltage appliances only — chargers, laptops, fans, TVs, LED lamps, consoles.

How it works

A Hub with no Wi-Fi saved creates its own temporary network. You join it with your phone, tell the Hub which router to use, and it restarts onto your network. Then you pair it to your account in the app.

Nothing is pre-programmed

Your Wi-Fi password is never compiled into the firmware. It is entered here, on the day, and stored on the unit — so the same firmware works on any network without being rebuilt.

Before you start2

Part 1 · Connect to Wi-Fi

Wi-Fi credentials

Printed on the unit. The last four characters are unique to this Hub.

The Hub's radio is 2.4 GHz only. A 5 GHz network will not appear in the list.

1

Power on the Hub

Plug the USB-C cable in and wait about ten seconds. A Hub that has never been set up creates its setup network automatically — there is no button to press.

2

Join the setup network

In your phone's Wi-Fi settings, pick the setup network above and enter its password. A “Sign in to network” notice appears within seconds — tap it. If nothing appears, open a browser and go to http://192.168.4.1

3

Choose your network

The page lists what the Hub can see, with signal strength beside each. Pick yours and type your Wi-Fi password. Nothing listed? Tap Rescan networks. Hidden router? Type its name into the hidden network box instead.

4

Save and connect

Tap Save and connect. The Hub restarts and joins your network, and the setup network closes — reconnect your phone to your normal Wi-Fi. If the password was wrong, the setup network reopens so you can try again.

Part 2 · Pair with your account

Device credentials

4–80 characters. Letters, numbers, _ and - only.

At least 8 characters. Both fields are case-sensitive.

5

Open the app

Sign in, then go to Settings → WattWise Hub.

6

Scan the code on page 5

Choose Scan QR code and point the camera at the next page. The app fills in both fields above and links the Hub. No camera? Choose Enter manually and copy them by hand.

7

Check that it reports

The Hub card shows a status chip. Within a minute it should read Online, and live readings should appear on the Dashboard.

Keep the token private

The device token lets a caller submit readings as this Hub. Do not post it, screenshot it, or send it in a message. If it gets out, issue a new one in the app — the old token keeps working briefly so the Hub does not drop out mid-change.

Part 2 · Pair with your account

Pairing code

Scan from Settings → WattWise Hub → Scan QR code.

Generating the code

Encode one of these three — the app accepts all of them:

{"deviceId":"ESP32_ROOM_A","token":"…"}

wattwise://device?deviceId=ESP32_ROOM_A&token=…

ESP32_ROOM_A|…

Use a generator that runs offline — pasting a real token into a website sends it to that website.

Codes are per unit. A second Hub needs its own code, its own Device ID and its own token.

If something goes wrong

Troubleshooting

What you seeWhat to do
Setup network not in the Wi-Fi list Unplug the Hub, wait five seconds, plug it back in. A Hub that already holds working Wi-Fi will not open one — reset it first (below).
The setup page never loads Go to http://192.168.4.1 directly. Turn mobile data off first — some phones route around a network with no internet.
No networks in the list Tap Rescan networks. The Hub sees 2.4 GHz only, so a 5 GHz-only network never appears.
Wrong Wi-Fi password entered Nothing to undo. The Hub reopens its setup network — rejoin and enter it again.
Setup network vanished mid-way It closes after 10 minutes and the Hub restarts. Power-cycle and start again from step 1.
Moving to a new router Hold BOOT for 5 seconds. Saved Wi-Fi is cleared and the setup network reopens. Pairing is not affected.
App shows the Hub offline Check the Reason line on the Hub card, then confirm the Device ID and token match page 4 exactly — both are case-sensitive.
